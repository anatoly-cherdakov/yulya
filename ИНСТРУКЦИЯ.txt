Юлия Лукина
Источник: https://run5k.run/users/yulya

1. Откройте GitHub-репозиторий именно этого сайта.
2. Замените index.html в корне репозитория. Добавьте рядом run5k-results.json
   и папку scripts с файлом fetch_run5k.py.
3. Для файла в скрытой папке используйте Add file → Create new file.
   Введите имя: .github/workflows/refresh-run5k.yml
   Скопируйте туда весь текст из файла refresh-run5k.yml, который лежит
   в корне архива, и нажмите Commit changes.
   Если файл с таким путём уже существует, замените его содержимое.
4. В Actions запустите «Обновление результатов: Юлия Лукина» → Run workflow.
   Дождитесь зелёной галочки.
   Если запрещена запись, включите Settings → Actions → General →
   Workflow permissions → Read and write permissions.
5. Откройте опубликованный сайт и нажмите «Обновить результаты».

Для адресов вида https://имя.github.io/репозиторий/ имя репозитория
определяется автоматически. Дополнительную папку внутри репозитория
создавать не нужно. Архивы трёх разных людей загружайте каждый в свой сайт.

Фоновая задача читает run5k.run каждые 15 минут; GitHub может задерживать
запуски. Кнопка получает последний подготовленный файл прямо из репозитория.
Добавляются только новые результаты после последней даты исходной таблицы.
Повторное нажатие не создаёт дублей. Добавления сохраняются в браузере.
Счётчики, статистика года, легенда и маркеры карты обновляются вместе.
Если новых результатов нет, таблица остаётся прежней.

Если GitHub отключит расписание из-за отсутствия активности репозитория,
включите его снова во вкладке Actions.
